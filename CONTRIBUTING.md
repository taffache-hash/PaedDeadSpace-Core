# Contributing

Bug reports, reproducibility problems, documentation corrections, and scientifically motivated pull requests are welcome.

For scientific/model issues, please identify the equation or assumption, provide the supporting source (preferably DOI/full citation), and distinguish empirical evidence from inference or proposed model construction. For software bugs, include the operating system, Python version, minimal reproduction steps, expected behavior, and observed behavior.

Changes to scientific equations or provenance should include tests and an explicit rationale. Clinical recommendations or patient-specific treatment rules are outside the project scope.
