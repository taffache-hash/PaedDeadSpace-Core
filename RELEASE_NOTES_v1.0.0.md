# PaedDeadSpace-Core v1.0.0

First public release of the PaedDeadSpace scientific engine. It includes the patient/apparatus dead-space framework, provenance metadata, model-boundary handling, 47 Core tests, 13 validation tests, and validation outputs.

The Pearsall golden case is included as a deterministic reproducibility benchmark. Numa–Fletcher remains an evidence-informed reference/sensitivity construction rather than a universal physiological default.

For educational and research use only; not for patient-specific clinical decision-making.
